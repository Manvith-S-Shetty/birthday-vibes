# Birthday Experience — Project Planning Pack

## Vision
Build a premium, interactive birthday-wishing web experience where a creator enters a person's name, password/PIN, date, message, photos, music and visual theme, then receives a private shareable birthday experience.

This is **not a static birthday card**. It is a cinematic, interactive mini-site designed to feel like a digital gift.

## Reference
The primary UX reference is 2Luv's birthday creation flow:
https://www.2-luv.com/en/create/birthday

We will study its creation simplicity, personalization flow, preview-first approach, private/password-protected concept, photos/music, interactive cards, and shareable experience, while creating our own visual identity and implementation rather than copying its branding or exact design.

## Build philosophy
1. Premium visual design first.
2. Very simple creator flow.
3. Every interaction should feel intentional.
4. Mobile-first recipient experience.
5. Real persisted data — not a static demo.
6. Live preview while creating.
7. Password/PIN-protected recipient experience.
8. Shareable unique URL and QR code.
9. Smooth animations with reduced-motion support.
10. Antigravity should plan, implement, run, inspect, and verify each milestone.
