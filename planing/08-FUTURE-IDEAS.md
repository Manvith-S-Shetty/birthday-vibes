# Future Experience Ideas

These are deliberately not V1 requirements.

## Cinematic scenes
- envelope opening
- film-strip transition
- camera shutter memory reveal
- handwritten signature
- scrapbook page turn
- starfield birthday universe

## Interactive memories
- tap photo to reveal a hidden note
- memory timeline
- "then vs now" slider
- rotating memory wheel

## Birthday mechanics
- blow candle using microphone
- tap-to-pop balloons
- scratch-off message
- gift box reveal
- wish-making interaction
- mini birthday quiz

## Personal touches
- voice message
- custom song
- favorite quotes
- inside jokes
- custom color palette
- custom font pairing

## Scheduling
A creator could prepare an experience now and configure it to become accessible on a future birthday date.

This should only be added after the core experience is stable.

## AI
Potential future AI capabilities:
- message drafting
- photo caption suggestions
- theme recommendation
- automatic memory ordering
- personalized animation pacing

AI should remain optional. The user's own photos and words must remain the emotional center.

## Immediate next action
Do not implement these yet. Keep them as the V2/V3 backlog.
